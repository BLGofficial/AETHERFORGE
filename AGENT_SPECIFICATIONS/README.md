# AETHER FORGE — SPECIALIST AGENT SPECIFICATIONS (`AGENT_SPECIFICATIONS/README.md`)

This directory contains the complete 10-dimension engineering specifications for all **19 Specialist Agents (`AGT-01` through `AGT-19`)** in the AETHER FORGE network.

## Mandatory 10-Dimension Specification Standard

Every agent specification in this directory defines:
1. **System Prompt Reference & Core Directive** (linked to verbatim prompt in [AGENT_PROMPTS/system-prompts-catalog.md](file:///C:/Users/blago/Desktop/AETHERFORGE/AGENT_PROMPTS/system-prompts-catalog.md))
2. **Role and Responsibilities**
3. **Domain Knowledge & Indexed Corpora**
4. **Tool Permissions (Allowlist, Action Tier Cap, Denied Tools)**
5. **Input / Output Schemas** (linked to [AGENT_CONTRACTS/multi-agent-contracts.md](file:///C:/Users/blago/Desktop/AETHERFORGE/AGENT_CONTRACTS/multi-agent-contracts.md))
6. **Memory Access (Read Scope, Write Scope, Scratchpad Namespace)**
7. **Task Execution Lifecycle**
8. **Delegation Policy**
9. **Failure Handling & Recovery**
10. **Evaluation Benchmarks** (linked to [AGENT_EVALUATION_FRAMEWORK.md](file:///C:/Users/blago/Desktop/AETHERFORGE/AGENT_EVALUATION_FRAMEWORK.md))
