# AETHER FORGE — Changelog

All notable changes for the `v1.0.0-rc1` engineering foundation and vertical slice program are documented in this file.

## [1.0.0] — 2026-11-23

### Added
- **Phase 13 (Native Compilation & FL Studio 2025 Python Bridge):** Compiled native Windows x64 `artifacts/native/AetherForge.WindowsWorker.exe` via Framework64 `csc.exe` with live Windows DPAPI (`ProtectedData`) and `FileAttributes.ReparsePoint` verification; verified FL Studio 2025 read-only Python controller script (`device_aetherforge_inspect.py`) on Python 3.14; completed `gain_normalize_pcm16_wav` in `workers/audio-engine/src/lib.rs`.
- **Phase 14 (Cloud Staging & Server-Side Provider Integration):** Implemented `ServerSideSecretManager` and `ManagedVendorProviderAdapter` (`openai`, `anthropic`, `google`, `self-hosted-openai-compat`) with zero-leakage guarantees; verified PostgreSQL 16 + `pgvector` DDL and Temporal Cloud namespace archival invariants.
- **Phase 15 (Dual-Control Production Promotion `v1.0.0`):** Enforced dual-control `Reviewer` + `ReleaseManager` separation in `SignedArtifactRegistry.promoteReleaseCandidateToProduction`, passed 5-iteration Stage 1 canary soak, and generated signed `artifacts/release-v1.0.0/` bundle with rehearsed rollback to `1.0.0-rc1`.

## [1.0.0-rc1] — 2026-11-23

### Added
- **Phase 00 (Foundation & Governance):** Product boundary, control loop, 5 invariants (`INV-01`..`INV-05`), 12-class action taxonomy, Emergency Stop protocol, [GOVERNANCE.md](./GOVERNANCE.md), [REFERENCE-BOOK.md](./REFERENCE-BOOK.md), [ADR-0001](./docs/adr/0001-hybrid-control-plane.md) through [ADR-0010](./docs/adr/0010-release-integrity.md), threat model, data classification policy, and phase-gated backlog.
- **Phase 01 (Contracts & Monorepo):** Strict TypeScript (`noImplicitAny`, zero `any` across boundaries) `pnpm` workspace, versioned Zod schemas (`@aether-forge/contracts` v1.0.0), canonical SHA-256 `computeCanonicalPlanHash`, generated JSON Schema Draft 2020-12 and OpenAPI 3.1.0 artifacts, and additive/breaking compatibility test suite.
- **Phase 02 (Identity, Tenancy & Governance Enforcement):** Configurable OIDC authentication seam, tenant-before-data isolation (`404 NOT_FOUND` cross-tenant semantics), role checks, idempotency deduplication middleware, append-only `AppendOnlyAuditStore` (`@aether-forge/audit`), approval state machine with `planHash`/`policyVersion` drift invalidation (`INV-03`), and `EmergencyStopController`.
- **Phase 03 (Policy-as-Code & Approvals):** Signed, versioned OPA Rego v1 bundle (`services/policy/bundles/v1/governance.rego`), `OpaPolicyDecisionPoint` (`@aether-forge/policy`), sanitized user-facing policy explanations, fail-closed evaluation, and `canonicalPathScope` enforcement.
- **Phase 04 (Durable Workflow & Web Control Plane):** `DurableTemporalOrchestrator` (`@aether-forge/orchestration`) with deterministic history replay, mid-wait worker restart recovery, transient activity retry, duplicate signal idempotency, and 4-screen Web Control Plane UI (`@aether-forge/web`).
- **Phase 05 (Provider Gateway & Bounded Planner):** `ProviderGatewayService` (`@aether-forge/provider-gateway`) with `PromptTemplateRegistry`, pre-egress credential/classification redaction fence, `TenantBudgetTracker`, `DeterministicFakeProviderAdapter`, `ToolManifestRegistry`, and `BoundedExecutionPlanner`.
- **Phase 06 (Windows Worker Trust Boundary):** `.NET 8` Windows Worker skeleton (`AetherForge.WindowsWorker.csproj`) + executable `WindowsWorkerHost` (`@aether-forge/windows-host`) and constrained filesystem adapter (`@aether-forge/filesystem`) defending against path traversal, NTFS junctions/reparse points, TOCTOU races, and unsigned/expired/revoked manifests.
- **Phase 07 (Knowledge & Evidence Substrate):** `EvidenceAddressableKnowledgeService` (`@aether-forge/knowledge`), PostgreSQL 16 + `pgvector` migration (`0001_knowledge_pgvector.sql`), `ImmutableLocalObjectStore`, mandatory chunk provenance citations, synchronous deletion propagation, and prompt-injection/malware quarantine.
- **Phase 08 (Offline Audio/DSP Engine):** Rust crate (`workers/audio-engine`) + executable PCM16 RIFF/WAVE offline DSP engine (`@aether-forge/audio-engine`) supporting `inspect_wav` and deterministic `gain_normalize` (`<0.01 dB` golden tolerance, bit-exact SHA-256 reproducibility, source immutability).
- **Phase 09 (FL Studio 2025 Qualification):** Empirical discovery of local FL Studio 2025 (`25.1.6.4997`) recorded in [docs/daws/fl-studio-2025-qualification.md](./docs/daws/fl-studio-2025-qualification.md); `FlStudio2025Adapter` (`@aether-forge/fl-studio-2025`) qualifying read-only `inspect` and backup-mandatory `non_destructive_edit` while blocking unqualified `session_mutation` and `render`.
- **Phase 10 (VST3 Product Boundary):** Isolated C++20 real-time processor core (`plugins/vst3/AetherForgeProcessor`), CMake build, static zero-allocation/zero-lock/zero-I/O source audit, 16-byte POD state round-trip, and shared DSP golden vector parity (`@aether-forge/vst3`).
- **Phase 11 (Observability, Security & Supply Chain):** W3C `traceparent` 5-boundary trace correlation (`@aether-forge/observability`), CycloneDX 1.5 SBOM, license & secret scanner, SLSA v1.0 provenance & signed artifact rollback (`@aether-forge/artifact-registry`), operational runbooks ([docs/operations/runbooks.md](./docs/operations/runbooks.md)), and 6-scenario abuse-case regression suite.
- **Phase 12 (Release Candidate Integration):** Full end-to-end vertical slice test (`tests/e2e/src/phase12-release-candidate.test.ts`), latency/throughput performance gate (`tests/performance/src/phase12-performance.test.ts`), and signed release attestation bundle (`artifacts/release-v1.0.0-rc1/`).
