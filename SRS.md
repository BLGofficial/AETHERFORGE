## 1. System Boundaries & Trust Zones

```text
[TB-1: Browser Client] ──(HTTPS + OIDC Bearer Token + W3C traceparent)──► [TB-2: Cloud Control Plane API / OPA Policy / Audit]
                                                                                ├──► [TB-3: Temporal Durable Orchestrator]
                                                                                ├──► [TB-4: Provider Gateway (Server-Side Secrets + Redaction Fence)]
                                                                                └──◄ [TB-5: Windows 11 Worker (Outbound-Only mTLS + DPAPI Identity)]
                                                                                        ├──► [TB-6: Constrained Filesystem / Git / Offline Rust Audio Engine]
                                                                                        └──► [TB-7: Qualified FL Studio 2025 Adapter / Isolated C++20 VST3 Core]
```

1. **Cloud Control Plane Boundary (`TB-1..TB-4`):** Owns identity, tenant isolation, specification/plan storage, OPA policy bundles, approvals, Temporal workflow scheduling, knowledge metadata, artifact signing, and LLM provider routing. Never accesses local workstation files directly and never accepts inbound connections from the cloud into customer networks.
2. **Local Workstation Execution Boundary (`TB-5..TB-7`):** Owns local filesystem operations, offline PCM16 WAV DSP processing, and qualified FL Studio 2025 (`25.1.6.4997`) interactions. Pulls signed `JobManifest` packages over outbound mTLS and verifies signatures, expiry, revocation, and canonical path confinement locally before execution.
3. **Real-Time VST3 Audio Thread Boundary (`TB-7 Isolated`):** Runs inside the host DAW process as a standalone C++20 binary (`AetherForgeProcessor`). Contains zero networking, orchestration IPC, heap allocations, mutex locks, filesystem I/O, or LLM calls.

## 2. Operational Constraints

- **CON-01 (OS & PowerShell Policy):** Workstation runs Windows 11 AMD64 (`10.0.26300.0`) with PowerShell `.ps1` script execution disabled; CLI tooling must invoke `.cmd` shims (`pnpm.cmd`, `npm.cmd`, `npx.cmd`) or direct binaries (`node`, `git`, `cmake.exe`, `csc.exe`, `python.exe`).
- **CON-02 (Host Native Compilers):** `csc.exe` (Framework64 C#), `cmake.exe` (`4.4.1`), and `python.exe` (`3.14`) are present and verified on host. External `.NET 8 SDK`, `Rust cargo/rustc`, and `MSVC/Clang + JUCE 8 + Steinberg VST3 SDK + pluginval` are absent on host; targets requiring those external SDKs must fail closed with `BLOCKED_MISSING_PREREQUISITES` until `package_install` approval is granted.
- **CON-03 (FL Studio 2025 Surface Constraint):** Installed FL Studio 2025 (`25.1.6.4997`) does not expose an official headless binary mutation SDK for `.flp` `FLdt` event streams; `session_mutation` and unattended background-service `render` remain hard-blocked (`DOMAIN_DAW_CAPABILITY_UNQUALIFIED`).
- **CON-04 (Secret & Private Asset Sovereignty):** Raw credentials (`SECRET_CREDENTIAL`) and private local audio/DAW files (`RESTRICTED_LOCAL`) are prohibited from external LLM provider egress by default.

| **REQ-F-0001** | **Typed Protocol Validation:** All ingress/egress payloads across REST, CloudEvents, planner tools, and worker manifests MUST validate at runtime against versioned Zod schemas (`schemaVersion: "1.0.0"`, `^1\.\d+\.\d+$`) with zero untyped `any`. | `@aether-forge/contracts` | 100% of canonical fixtures pass; major version `2.0.0` or missing required fields throw validation error; static scan finds `0` `any` tokens in `contracts/src/**/*.ts`. |

| **REQ-F-0003** | **Prompt Template Registry Verification:** `ProviderGatewayService` MUST verify `templateId`, `templateVersion`, and SHA-256 `templateSha256` against `PromptTemplateRegistry` before executing any model request. | `@aether-forge/provider-gateway` | Unregistered or hash-tampered `PromptTemplateRef` fails closed with `DOMAIN_PROMPT_TEMPLATE_UNREGISTERED`. |

| **REQ-F-0009** | **Deterministic OPA Policy Evaluation & UI Explanations:** `OpaPolicyDecisionPoint` MUST evaluate `PolicyInput` against signed Rego v1 bundle rules across all 11 action classes, default unknown actions or missing/corrupted bundles to `deny`, and return a sanitized `userExplanation` free of internal Rego/key/path strings. | `@aether-forge/policy` | All 11 action classes match governance matrix; unloaded bundle returns `POLICY_BUNDLE_UNAVAILABLE_FAIL_CLOSED`; `userExplanation` matches zero sensitive regex patterns. |
| **REQ-F-0010** | **Cryptographic Approval Binding & Drift Invalidation:** `ApprovalStateMachine` MUST bind approvals and HMAC-signed `CapabilityGrant` tokens to `(tenantId, projectId, planHash, policyVersion, canonicalPathScope, expiresAt)` and invalidate them immediately if `planHash` or `policyVersion` changes (`INV-03`). | `@aether-forge/api` | Mutating plan steps or rotating policy bundle (`v1 → v2`) after approval causes `verifyStepDispatchGate` to fail with `DOMAIN_APPROVAL_INVALIDATED_BY_DRIFT` (HTTP 409). |
| **REQ-F-0011** | **Durable Temporal Workflow Replay & At-Most-Once Execution:** `DurableTemporalOrchestrator` MUST persist deterministic workflow history, recover mid-wait state across worker restarts, retry transient activity failures, deduplicate approval signals, and execute side-effecting steps at most once. | `@aether-forge/orchestration` | Mid-wait restart + 2 transient failures + duplicate approval signal results in `status === "COMPLETED"` and `simulatedWriteCount === 1`. |

| **REQ-F-0015** | **Evidence-Addressable Knowledge Ingestion & Quarantine:** `EvidenceAddressableKnowledgeService` MUST reject `SECRET_CREDENTIAL` and unsupported MIME types, quarantine payloads containing raw secrets, executable/script headers, or prompt-injection directives (`DOMAIN_KNOWLEDGE_INPUT_QUARANTINED`), and store active sources in `ImmutableLocalObjectStore` with SHA-256 `contentHash`. | `@aether-forge/knowledge` | Quarantined sources record `status: "QUARANTINED"` and index `0` retrievable chunks. |
| **REQ-F-0016** | **Provenance-Cited Retrieval & Synchronous Deletion Propagation:** Every retrieved `GroundedContextChunk` MUST include `citation: { sourceId, contentHash, location, classification, extractionVersion }` and `uncitedInferenceLabel: "model_inference"`. Deleting a source MUST synchronously purge its immutable object and all chunks. | `@aether-forge/knowledge` | 100% of retrieved chunks carry line-range citations; post-delete and cross-tenant queries return `0` chunks. |
| **REQ-F-0017** | **Deterministic Offline PCM16 WAV Inspection & Gain Normalization:** `@aether-forge/audio-engine` MUST validate 16-bit linear PCM RIFF/WAVE framing and resource quotas (`maxInputBytes`, `maxDurationSeconds`, `maxExecutionTimeMs`), prohibit overwriting `inputPath` (`DOMAIN_AUDIO_OVERWRITE_SOURCE_FORBIDDEN`), and normalize peak amplitude to `targetPeakDbfs` within `<0.01 dB` tolerance with bit-exact SHA-256 reproducibility. | `@aether-forge/audio-engine`, `workers/audio-engine` | Golden 48 kHz stereo WAV normalized to `-1.0 dBFS` measures within `<0.01 dB`; two runs produce identical `outputSha256`; source SHA-256 is unchanged. |
| **REQ-F-0018** | **Tier-Qualified FL Studio 2025 Adapter:** `FlStudio2025Adapter` MUST probe installed FL Studio 2025 binaries (`25.1.6.4997`), qualify only `inspect` (`FLhd`/`FLdt` + `0xC7` `FLP_Version` parsing) and `non_destructive_edit` (requiring `backupRequired: true` and `.bak` creation), and fail closed on `session_mutation`, `render`, or `foregroundUiFallbackOptIn: true`. | `@aether-forge/fl-studio-2025` | Real factory `.flp` (`NewStuff.flp`, `45` ch, `96` PPQ) inspects cleanly; `session_mutation` and `render` fail with `DOMAIN_DAW_CAPABILITY_UNQUALIFIED`. |
