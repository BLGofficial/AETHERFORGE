## 1. Four-Category Capability Classification Matrix

Per platform governance ([GOVERNANCE.md](./GOVERNANCE.md)) and [ADR-0002](./docs/adr/0002-controlled-autonomy-policy-engine.md) / [ADR-0009](./docs/adr/0009-fl-studio-2025-qualification-layer.md), every capability is classified across four orthogonal dimensions:
1. **Native Platform Capabilities** (built-in and operational inside the 26-package AETHER FORGE monorepo)
2. **Capabilities Provided Through External Tools / Runtimes** (delegated through verified adapters or host toolchains)
3. **Capabilities Requiring Human Approval** (gated by OPA `requireApproval` and cryptographic `CapabilityGrant`)
4. **Capabilities Not Currently Supported / Blocked** (hard-denied at runtime with explicit error codes)

| Capability Area | 1. Native Platform Capability | 2. Provided via External Tool / Runtime | 3. Human Approval Requirement | 4. Currently Unsupported / Blocked |
