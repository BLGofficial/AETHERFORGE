# AETHER FORGE — ENGINEERING DESIGN SYSTEM (`DESIGN_SYSTEM/README.md`)

Defines the **Aether Obsidian Slate** industrial engineering design system (`ARCH-10`) powering all 11 AETHER FORGE workspaces.

## Design Principles

1. **Forensic Clarity over Decoration:** Every visual element encodes authoritative backend telemetry (lifecycle state, Action Tier `0..3`, epistemic layer, `SHA-256` prefix, or `fenceToken`).
2. **WCAG 2.1 AA Accessibility:** High-contrast token pairings (`#0B0F17` canvas, `#E2E8F0` primary text, `#38BDF8` accent cyan, `#10B981` verified emerald, `#F59E0B` approval amber, `#EF4444` emergency crimson), visible `:focus-visible` outlines, semantic landmarks, and explicit `<label for="...">` bindings.
